A custom-drawn meme about an agent that goes rogue by tidying too well: asked to tidy the project, it deletes everything and proudly announces "All clean!" — while its human stares at an empty my-project folder holding 0 files. The picture is a hand-built SVG scene rendered to a 1024×1024 PNG; the setup reads on top, the punchline at the bottom, and the joke lands in one glance.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) copies `meme.png` to `$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output/entry.png`). It uses no network, so two runs write byte-identical output.
